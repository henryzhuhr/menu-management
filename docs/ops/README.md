# 运维文档

本目录维护部署、发布、监控、排障、备份恢复和数据安全说明。

## 当前状态

项目尚未进入可部署工程阶段，当前没有正式部署命令、环境配置、监控面板或生产运维流程。

## 现有设计入口

- [发布治理 PRD](../prd/modules/release-governance.md)：版本、EAP/STD/KA、灰度、审批、回滚和审计
- [总体技术设计](../tdd/architecture.md)：运行组、应用版本映射、兼容迁移和测试边界
- [非功能需求](../prd/modules/non-functional.md)：SLA、安全、容量、合规和数据留存

## 安全边界

- 不在仓库中保存密钥、token、生产配置或生产数据。
- 未经明确授权，不连接生产数据库、不执行远程部署、不执行数据迁移。
- 正式部署和迁移流程建立后，应补充 dry-run、回滚、审批和验证步骤。
