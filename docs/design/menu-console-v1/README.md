# 菜单管理控制台 UI 原型 v1

本目录保存统一菜单中心的首版本地 UI 设计原型，用于在进入工程实现前校准页面信息架构、管理后台布局和移动端适配方向。

## 文件

- `index.html`：Web 端与 iPhone 17 Pro 端的双画板静态原型入口
- `styles.css`：设计样式、布局、视觉 token 和响应式查看方式

## 设计范围

- Web 端：菜单管理控制台，覆盖顶部上下文、左侧导航、菜单树、节点详情、可见性诊断、发布状态。
- iOS 端：按 iPhone 17 Pro 逻辑尺寸 `402 x 874` 设计，覆盖移动端菜单树、诊断摘要、发布入口和底部导航。
