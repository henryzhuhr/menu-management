# 开发文档

本目录维护本地开发、代码变更、测试和验证说明。

## 当前状态

项目尚未初始化正式应用代码、包管理文件或统一启动命令。当前阶段以 PRD、TDD、路线图和设计原型为主。

## 开发入口

- [技术设计](../tdd/README.md)：工程边界、接口、数据模型和测试设计
- [产品需求](../prd/README.md)：实现所需的业务规则和验收标准
- [设计原型](../design/menu-console-v1/README.md)：控制台页面原型

## 验证约定

- 文档变更至少运行 `git diff --check`，并检查内部链接和决策引用。
- UI 原型按 TDD 约定使用 `agent-browser` 做页面和交互验证。
- 工程代码初始化后，在本文件补充安装、启动、格式化、单元测试和端到端测试命令。
- 未运行的检查必须在交付说明中列出原因和剩余风险。

## 变更边界

- 遵循相邻文件和已有设计，不为简单需求引入新的工具链。
- 数据库 schema 变更先更新 TDD，再补迁移、兼容策略和测试。
- 生成文件不要直接手改，应使用项目约定的生成命令。
