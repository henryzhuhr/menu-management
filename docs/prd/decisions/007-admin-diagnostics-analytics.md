# 管理、诊断和分析决策

<a id="d013-admin-modules"></a>
## D013 管理入口

- 提问：管理后台需要覆盖哪些配置入口？
- 提问解释：该问题用于确认管理后台是只覆盖平台菜单，还是覆盖完整配置治理。
- 用户决策：全量配置。
- 需求影响：平台菜单、功能点/套餐映射、租户订阅结果查看、租户自定义、版本发布和灰度策略都在菜单中心管理；租户订阅主数据源以后续 [D055](./006-integrations.md#d055-subscription-source-of-truth) 为准。

<a id="d032-preview-requirements"></a>
## D032 发布预览

- 提问：发布前是否需要预览最终菜单结果？
- 提问解释：该问题用于确认发布前是否需要按上下文验证最终运行时结果。
- 用户决策：多维预览。
- 需求影响：可按应用、环境、地域、租户、用户、语言和客户端预览最终菜单树。

<a id="d033-configuration-channels"></a>
## D033 配置方式

- 提问：菜单和策略配置主要通过什么方式管理？
- 提问解释：该问题用于确认配置只通过后台页面，还是需要批量迁移和自动化配置能力。
- 用户决策：后台 + 导入导出。
- 需求影响：提供管理后台，同时支持批量导入导出，适合大量菜单和多环境迁移。

<a id="d046-usage-analytics"></a>
## D046 使用分析

- 提问：是否需要菜单使用分析能力？
- 提问解释：该问题用于确认是否需要菜单曝光、点击和报表能力。
- 用户决策：完整分析。
- 需求影响：提供多维报表、漏斗、租户对比、地域对比和导出。

<a id="d047-config-migration"></a>
## D047 配置迁移

- 提问：导入导出主要用于什么场景？
- 提问解释：该问题用于确认导入导出的主要目标是跨环境迁移、批量维护还是备份恢复。
- 用户决策：跨环境迁移。
- 需求影响：支持从测试到生产迁移应用菜单、功能点、策略和版本配置。

<a id="d048-diagnostics"></a>
## D048 查询排障

- 提问：是否需要面向管理员的菜单排障能力？
- 提问解释：该问题用于确认诊断能力只展示最终结果，还是需要解释完整过滤链路。
- 用户决策：完整诊断。
- 需求影响：提供条件命中、权限、订阅、版本、缓存、依赖调用等完整诊断链路。
