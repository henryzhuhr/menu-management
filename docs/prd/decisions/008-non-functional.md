# 非功能决策

<a id="d024-scale-target"></a>
## D024 规模目标

- 提问：需求层面按什么规模目标设计验收？
- 提问解释：该问题用于确认需求目标是中型 SaaS、大型平台，还是暂不设规模。
- 用户决策：大型平台。
- 需求影响：需求需要覆盖多租户、多地域、多应用和复杂灰度，强调缓存、稳定性和治理。

<a id="d050-service-slo"></a>
## D050 服务指标

- 提问：运行时菜单服务的非功能目标按什么强度定义？
- 提问解释：该问题用于确认是否需要量化运行时菜单服务的可用性、延迟和错误率。
- 用户决策：核心链路 SLA。
- 需求影响：菜单运行时作为核心链路，需要明确 SLA、P95/P99、错误率和降级策略。

<a id="d051-retention-policy"></a>
## D051 数据留存

- 提问：审计、版本和分析数据需要保留多久？
- 提问解释：该问题用于确认历史数据保留是固定期限、长期保留，还是可按类型配置。
- 用户决策：可配置保留。
- 需求影响：不同租户、地域或数据类型可配置保留期限。

<a id="d052-sla-target"></a>
## D052 SLA 指标

- 提问：运行时菜单查询的 SLA 目标按哪档定义？
- 提问解释：该问题用于量化运行时菜单查询的可用性和性能目标。
- 用户决策：99.9% + P95 200ms。
- 需求影响：运行时菜单查询目标可用性为 99.9%，性能目标为 P95 200ms。

<a id="d053-capacity-target"></a>
## D053 容量量级

- 提问：需求验收按什么容量量级描述？
- 提问解释：该问题用于进一步细化大型平台的容量目标。
- 用户决策：超大平台。
- 需求影响：需求按千应用、万租户、多地域高并发设计验收；该决策细化并提升 [D024](#d024-scale-target) 的规模目标。

<a id="d054-compliance-scope"></a>
## D054 合规安全

- 提问：安全与合规需求按什么范围定义？
- 提问解释：该问题用于确认合规需求是基础租户隔离，还是企业合规或强监管。
- 用户决策：租户隔离 + 审计。
- 需求影响：强调租户数据隔离、权限最小化、完整审计、敏感信息不泄露。
