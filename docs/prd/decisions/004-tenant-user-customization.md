# 租户与用户个性化决策

<a id="d010-tenant-custom-scope"></a>
## D010 租户自定义边界

- 提问：租户自定义菜单允许做到什么程度？
- 提问解释：该问题用于确认租户是完全独立维护菜单，还是继承平台模板后扩展。
- 用户决策：继承 + 扩展。
- 需求影响：租户继承平台菜单模板，可新增租户私有菜单、隐藏部分菜单、调整租户内排序。

<a id="d016-tenant-change-flow"></a>
## D016 租户变更流程

- 提问：租户自定义菜单变更如何生效？
- 提问解释：该问题用于确认租户变更是保存即生效，还是也需要草稿和发布流程。
- 用户决策：租户草稿发布。
- 需求影响：租户管理员维护草稿并发布到本租户，关键变更需要平台审批。

<a id="d023-user-personalization"></a>
## D023 用户个性化

- 提问：是否把用户个人菜单偏好纳入需求？
- 提问解释：该问题用于确认普通用户是否可以收藏、排序或隐藏菜单。
- 用户决策：用户可排序隐藏。
- 需求影响：用户可以调整自己的菜单顺序或隐藏菜单，但不改变权限和订阅可见性。

<a id="d026-mandatory-menu"></a>
## D026 强制菜单

- 提问：是否需要支持不可隐藏或强制展示的菜单？
- 提问解释：该问题用于确认平台或租户是否能保护关键菜单不被用户个性化隐藏。
- 用户决策：支持。
- 需求影响：平台或租户可标记关键菜单为不可被用户隐藏或重排，但仍需满足权限和订阅。

<a id="d031-tenant-conflict-resolution"></a>
## D031 冲突处理

- 提问：平台菜单模板升级与租户自定义冲突时，需求如何处理？
- 提问解释：该问题用于确认平台升级是否覆盖租户自定义，还是需要显式处理冲突。
- 用户决策：显式冲突处理。
- 需求影响：系统标记冲突，并要求管理员确认合并、保留租户覆盖或回退。

<a id="d042-sort-precedence"></a>
## D042 排序优先级

- 提问：平台排序、租户排序、用户排序冲突时如何处理？
- 提问解释：该问题用于确认最终菜单排序由哪一层优先决定。
- 用户决策：用户 > 租户 > 平台。
- 需求影响：在可见且非强制约束范围内，用户排序优先，其次租户，最后平台默认排序。
