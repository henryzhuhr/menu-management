# 菜单模型决策

<a id="d007-menu-ownership"></a>
## D007 菜单归属

- 提问：菜单结构由谁维护，租户是否能改菜单结构？
- 提问解释：该问题用于确认菜单是平台统一维护，还是允许租户参与结构定义。
- 用户决策：租户可自定义。
- 需求影响：菜单模型需要支持平台模板和租户扩展/覆盖。

<a id="d011-menu-node-types"></a>
## D011 菜单节点类型

- 提问：菜单节点需要覆盖哪些类型？
- 提问解释：该问题用于确定左树和导航模型的基本节点类型。
- 用户决策：目录、页面、外链。
- 需求影响：菜单节点需要支持层级目录、内部路由页面和外部链接。

<a id="d015-runtime-payload"></a>
## D015 运行返回

- 提问：后端返回给前端的运行时数据包含什么？
- 提问解释：该问题用于确认后端只返回树结构，还是也负责导航元数据。
- 用户决策：菜单和导航元数据。
- 需求影响：运行时接口需要返回路由、图标、排序、打开方式、面包屑等导航信息。

<a id="d019-env-region-semantics"></a>
## D019 环境地域语义

- 提问：环境和地域在需求中如何影响菜单？
- 提问解释：该问题用于确认环境和地域只是发布范围，还是允许菜单内容不同。
- 用户决策：内容可不同。
- 需求影响：菜单内容、名称、链接和规则都需要支持按环境和地域差异化。

<a id="d020-i18n-scope"></a>
## D020 国际化范围

- 提问：菜单名称和导航信息是否需要国际化？
- 提问解释：该问题用于确认菜单文案是单语言、双语还是多语言。
- 用户决策：多语言。
- 需求影响：菜单展示文案需要支持多语言配置和运行时语言选择。

<a id="d022-left-tree-experience"></a>
## D022 左树体验

- 提问：前端左树除了展示菜单树，还需要哪些用户体验能力？
- 提问解释：该问题用于确认前端导航只做基础展示，还是包含搜索、收藏或个性化布局。
- 用户决策：个性化布局。
- 需求影响：运行时菜单需要支持用户个性化展示需求，并与权限和强制菜单规则协同。

<a id="d034-client-scope"></a>
## D034 客户端范围

- 提问：运行时菜单主要服务哪些客户端形态？
- 提问解释：该问题用于确认菜单中心是否只服务 Web 左树，还是需要抽象支持多种客户端。
- 用户决策：多客户端。
- 需求影响：菜单模型需要抽象为跨客户端可复用的逻辑菜单。

<a id="d035-language-fallback"></a>
## D035 语言回退

- 提问：多语言文案缺失时如何回退？
- 提问解释：该问题用于确认缺失翻译时的运行时行为和发布约束。
- 用户决策：默认语言回退。
- 需求影响：运行时按用户语言取文案，缺失时回退到应用默认语言。

<a id="d036-delete-semantics"></a>
## D036 删除语义

- 提问：菜单、功能点、套餐等配置删除应如何处理？
- 提问解释：该问题用于确认配置删除是否允许物理删除，以及如何支持历史和回滚。
- 用户决策：停用归档。
- 需求影响：核心配置默认不物理删除，通过停用或归档保留历史。

<a id="d037-multi-client-model"></a>
## D037 多端模型

- 提问：多客户端菜单模型如何定义？
- 提问解释：该问题用于确认是每端独立维护菜单树，还是同一逻辑菜单绑定不同端展示。
- 用户决策：逻辑菜单 + 端展示。
- 需求影响：权限、订阅和条件规则在逻辑菜单上复用，客户端差异通过展示元数据表达。
