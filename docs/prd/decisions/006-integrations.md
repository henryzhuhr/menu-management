# 外部集成决策

<a id="d005-permission-ownership"></a>
## D005 权限归属

- 提问：用户权限本身由谁负责管理？
- 提问解释：该问题用于确认菜单中心是否内置完整权限体系，还是只消费外部权限结果。
- 用户决策：对接权限系统。
- 需求影响：菜单中心消费外部权限结果或权限标识，不负责完整用户、角色和授权体系。

<a id="d029-dependency-failure"></a>
## D029 依赖故障

- 提问：外部权限系统或订阅依赖不可用时，运行时菜单如何处理？
- 提问解释：该问题用于确认外部依赖异常时是安全优先、可用性优先，还是直接失败。
- 用户决策：安全降级。
- 需求影响：无法确认权限或订阅时不展示受控菜单，只返回明确可公开或可确认的菜单。

<a id="d030-admin-rbac"></a>
## D030 管理角色权限

- 提问：管理后台角色权限需要精细到什么程度？
- 提问解释：该问题用于确认管理后台使用固定角色、分层角色，还是完全对接外部权限系统。
- 用户决策：完全可配置。
- 需求影响：管理后台自身也接入外部权限系统，所有管理操作按权限点控制。

<a id="d049-external-integrations"></a>
## D049 外部系统

- 提问：菜单中心需要对接哪些外部系统作为需求边界？
- 提问解释：该问题用于确认身份、权限、订阅哪些能力由外部系统提供。
- 用户决策：身份 + 权限 + 订阅。
- 需求影响：菜单中心对接身份认证、权限系统、租户/订阅或产品套餐系统，负责整合结果。

<a id="d055-subscription-source-of-truth"></a>
## D055 订阅主源

- 提问：租户订阅和套餐的主数据源是谁？
- 提问解释：该问题用于消除菜单中心管理套餐/功能点与外部订阅系统之间的职责冲突。
- 用户决策：外部订阅为主。
- 需求影响：外部订阅系统是主源，菜单中心维护功能点与菜单映射，并消费订阅结果。

<a id="d056-feature-source-of-truth"></a>
## D056 功能点主源

- 提问：功能点本身由谁定义？
- 提问解释：该问题用于确认功能点编码和名称由菜单中心、产品系统还是各应用维护。
- 用户决策：菜单中心定义。
- 需求影响：菜单中心维护功能点编码、名称、多语言和与菜单的绑定，外部订阅只返回租户拥有的功能点。

<a id="d057-subscription-mismatch"></a>
## D057 订阅异常

- 提问：外部订阅结果和菜单中心功能点配置不一致时怎么处理？
- 提问解释：该问题用于确认订阅异常时是安全隐藏、尽量展示，还是忽略外部异常。
- 用户决策：安全隐藏 + 告警。
- 需求影响：无法匹配或已停用功能点对应菜单不展示，并产生诊断或告警。
