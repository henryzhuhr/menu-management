# 可见性规则决策

<a id="d003-filter-rules"></a>
## D003 过滤规则复杂度

- 提问：菜单可见性过滤规则先按哪种复杂度定义？
- 提问解释：该问题用于确认只做权限过滤，还是覆盖订阅、权限和更多策略条件。
- 用户决策：多条件策略。
- 需求影响：菜单可见性需要同时支持订阅、权限、启停、灰度、环境、时间、地域等条件。

<a id="d008-subscription-model"></a>
## D008 订阅模型

- 提问：租户订阅能力应如何表达？
- 提问解释：该问题用于确认订阅是直接绑定菜单，还是通过套餐和功能点间接影响菜单。
- 用户决策：套餐 + 功能点。
- 需求影响：菜单节点需要绑定功能点，租户订阅结果决定是否具备功能点。

<a id="d012-permission-binding"></a>
## D012 权限绑定

- 提问：菜单和外部权限系统的关系怎么定义？
- 提问解释：该问题用于确认菜单绑定角色、权限标识，还是由外部权限系统直接返回菜单。
- 用户决策：绑定权限标识。
- 需求影响：菜单中心维护菜单与权限标识关系，运行时根据用户权限结果过滤。

<a id="d017-runtime-context"></a>
## D017 用户上下文

- 提问：运行时菜单查询需要哪些上下文作为输入？
- 提问解释：该问题用于确认运行时过滤是否需要应用、环境、地域、租户和用户等上下文。
- 用户决策：应用 + 租户 + 用户。
- 需求影响：运行时请求需要携带应用、环境、地域、租户和用户身份，权限由菜单中心调用或接收外部权限结果。

<a id="d018-default-visibility"></a>
## D018 默认安全策略

- 提问：权限、订阅或条件信息缺失时，菜单默认如何处理？
- 提问解释：该问题用于确认系统是安全优先隐藏，还是体验优先展示。
- 用户决策：默认隐藏。
- 需求影响：缺权限、缺订阅、条件不满足或上下文不完整时不返回菜单。

<a id="d025-visibility-precedence"></a>
## D025 规则优先级

- 提问：菜单最终可见性规则优先级按哪种定义？
- 提问解释：该问题用于确认租户自定义、用户个性化和安全规则之间的优先级。
- 用户决策：安全优先。
- 需求影响：发布、启用、订阅、权限和条件必须先满足，再应用租户自定义和用户个性化。

<a id="d038-condition-model"></a>
## D038 条件策略模型

- 提问：多条件过滤策略如何表达？
- 提问解释：该问题用于确认条件策略是内置类型、可配置表达式，还是外部策略引擎结果。
- 用户决策：内置条件类型。
- 需求影响：先定义环境、地域、客户端、租户、套餐、权限、时间窗、灰度标签等标准条件。

<a id="d039-feature-relation"></a>
## D039 功能点关系

- 提问：功能点和菜单的绑定关系应如何定义？
- 提问解释：该问题用于确认菜单、功能点、套餐之间的产品关系。
- 用户决策：菜单绑定功能点。
- 需求影响：菜单节点绑定一个或多个功能点，租户订阅功能点后才可能看到菜单。

<a id="d040-binding-semantics"></a>
## D040 绑定语义

- 提问：菜单绑定多个功能点或权限标识时，如何判断满足？
- 提问解释：该问题用于确认多个绑定项默认是全部满足、任一满足，还是节点可配置。
- 用户决策：节点可配置。
- 需求影响：节点条件组合需要支持 AND/OR 配置，并能被诊断解释。

<a id="d041-tree-visibility"></a>
## D041 父子展示

- 提问：父子菜单可见性如何处理？
- 提问解释：该问题用于确认父目录是否独立判断，以及空目录是否展示。
- 用户决策：父随子显示。
- 需求影响：目录节点自身满足条件或存在可见子节点时显示，空目录不显示。
