# PRD README

本目录维护项目的需求文档。

这里采用持续更新的方式，不是一需求一份文档。先在现有文档里补内容，只有在内容明显变多时再拆子文档。

## 目标

PRD 只需要回答几个最基本的问题：

- 要做什么
- 为什么要做
- 这次包含什么，不包含什么
- 关键规则是什么
- 怎么算做完

## 建议写法

如果是一个新功能，通常补这几项就够了：

- 背景
- 目标
- 范围
- 关键规则
- 验收标准

## 维护规则

- 优先更新现有文档，不默认新建新文件
- 文档写到“够继续开发”即可，不追求完整大而全
- 如果需求变了，顺手把文档改掉，避免文档和代码脱节
