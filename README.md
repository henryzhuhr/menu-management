# menu-management

菜单管理系统。

## 简介

这是一个用于菜单信息维护与管理的项目，目标是提供清晰、可扩展的菜单管理能力。

当前仓库仍在早期建设阶段，功能与文档会持续完善。

## 功能方向

- 菜单管理
- 分类管理
- 菜单项管理
- 搜索与筛选
- 页面验证与自动化测试
